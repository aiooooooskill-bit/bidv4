## 已实施的修复

1. **失效判断按真实依赖。** 解读及下游阶段只跟踪已选招标来源，写作准备统一口径；制作时实际读取、注入的参考件单独登记版本并随派发继承。无关上传件不再改变阶段版本，已采用资料、主体、指引变化仍须重新核验。删除已选来源会返回明确缺失状态，保持状态页可用并使相关成果失效。
2. **Word 批注作为完整独立证据。** 保存原编号、全文及段落／表格锚点，失去锚点的批注也保留并标为未定位。正文解析稿及行号不变，原解读复用路径保留。审核准备回执一次交付全文，后续批次和状态查询只带版本、路径和范围。批注不能充当已印入正文的承诺、独立成本计算依据或正文参数冲突证明。
3. **写手绑定自己的章节。** 开工前将全部节名解析成当前目录规范路径并持久记录，未知／多义节名不启动写手，不静默丢弃部分请求。先识别完整标题再拆多节任务，避免把“附件1、单位负责人身份证明”等标题中的顿号拆错。重复占用、跨章写入、子任务修改共享准备或合册均被拦截；排队取得写入锁后再检查是否停止／换轮。
4. **正文推理开放有界并行。** 仅正文 task 声明官方 `isConcurrencySafe`，上限 8，支持排队取消；目录等任务保持原有调度，项目写入锁、DOCX 文件锁及原子落盘保留。复用 DeepSeek 官方子任务生命周期，没有重写 Agent loop。

静态技能、角色与预设共 **28 份提示词相关文件逐字相同**。程序生成的章节路径、证据类型说明和错误回执发生变化；不能表述为模型收到的全部上下文字节相同。

灵燕参考仅限本机安装版的程序：7 个关键模块与公开 v0.2.3 规范化代码指纹匹配，其任务／模型并发上限为 8。本轮未读取灵燕用户配置或业务工作区，也没有用生产项目做性能或成品对比。本轮未复制其完整自适应全局模型限流器，不把 8 个正文槽位说成全局所有模型请求的限流保证。

### 人工复核尚未过关的项目

- **风险触发依据外推。** 修复组将“报价为空”列为可能无效风险，但关联的三段原文均规定“报价超最高限价才无效”；其自身评估也写了“无法判断是否超限”。应补充明确的缺报报价后果条款，或保留需确认，不能用超限条款单独支撑这个分类。缺报价事实继续保留，不为降低风险数量而隐藏问题。本轮保留原始模型报告，没有手工改成漂亮结果。
- **版式仍需改进。** 同一 QA 渲染器下，物理页数 87 → 134，可提取文字 27,479 → 28,689，图片 13 → 60。图片与素材选择不同，不能以页数多判定质量好。两组响应表都有窄列长行纵向挤排、末尾签章孤页；续页末行可见，不能误报为表格内容丢失。抽查了声明、成本、响应表及末页，未声称逐页、逐图人工审完。
- **既有检查提示保留。** 最终全局检查仍有复合字段／图片事实无法逐字比对、未提供资料及疑似重复等提醒。未自动关闭这些提醒，也未把程序通过等同于报价、资质和承诺已经核实。

因此本轮可以确认三项确定性缺陷修复与真实并行生效，**不能确认整体稿件已经达到可直接交付或同项目人工稿质量**。成本说明与合同价格仍需真实数据和凭证，生产环境不参与比较。

## 测试与版本口径

最终代码通过 **735 项业务测试、13 项原生链路测试及 7 项边界回归**。独立测试夹具不进行真实模型推理，完整模型链两组所有实际请求均为 Flash。

完整模型链运行期间两组源码均冻结。运行结束后补了“删除已选来源导致状态异常”的边界保护；该分支未在正常包3成稿中触发。最终隔离代码对同一批完成成果重新执行原解读、正文和整份审核门禁：24 章仍 ready，Word 字节不变，全部正常阶段版本与模型链快照相同。删除来源则单独经实际删除路由和页面状态 runner 回归。未为这条缺失分支再次向模型发送整本资料；真实用量仍取冻结模型链原记录，版本差异完整保留。

本次为两次独立生成的单组前后实测，包含服务、缓存和输出差异，8.4% 不是稳定时延保证。误失效修复主要避免后续无关资料变更引起的重复工作；干净首次成稿没有触发这类变更，不能将它的收益虚构成首次成稿 token 降低。

## 下一轮建议

1. 先补审核“适用范围成立”和“风险触发事实成立”的区分；对数值超限等风险核对真实响应数值与源阈值，原文缺证据就要求补证，不任意升级或自动降级风险。
2. 目录错误回执返回已冻结的规范 kind/reason，追加路径复用原值；汇总由已校验分册作机械合并与差异核对，减少模型反复重写同一大目录。保留原分类和来源门禁。
3. 按目录决策点、审核批次收束活动历史，旧完整事件／证据按版本外置，当前上下文只携带必要状态和原文引用入口；用户原话、确认问答、未完成工具对必须保留。
4. 在导出代码层处理表格所属节、列宽与行距、续页表头、签章同页，并核对素材图的章节适用范围。继续保留原正文、格式约束和业务提示词，不靠删证据、降预算或跳过审核提速。
