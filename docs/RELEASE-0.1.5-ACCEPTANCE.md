# 0.1.5 发布复核

按项目 AGENTS.md 与 review-agent 对隔离分支合并范围复核。范围包含目录派发、评分对齐、汇总门禁、附件归位、既有正文归集与合册、正文与原生标题格式，以及正式源码中尚未提交的资料库和错误恢复改动。

## 当前交付约定

本轮用户最后确认：只导出可编辑 Word，不安装或调用 LibreOffice，不导出 PDF；接受由打开文档的 Office/WPS 计算分页。目录、标题及页脚使用原生编号与域，文档请求打开时更新。平台不将字段存在或网页预览当作实际分页已完成。原先 Word/PDF 成对排版的测试记录只代表旧方案，不能作为当前方案的分页证明。

正文默认宋体、小四、1.5倍行距，招标明确要求优先；封面独立分节不计页码，目录从1开始，正文、附件连续编号，总页数字段指向最后正文位置。自定义奇偶页页眉保留，默认、偶数页和首页页脚同步设置。

## 复核结果

No findings.

发现的可执行问题已经修复并复验：锁定PDF输入解析依赖的接口、缺失附件仍可发布、旋转图片比例、含标点标题引用、中文字号匹配，以及下载稿损坏后的重新导出恢复。LibreOffice与PDF输出实现已随最新需求删除，未保留兼容层。

实际字体和分页由使用者的Office/WPS与可用字体决定；当前Word没有执行宏。Windows/Linux尚无实机验收，也没有对本轮所有长文档在不同版本Office/WPS内逐页重新验收，不将旧PDF逐页结果当成此项通过。

业务数据不进入Git提交或插件包；正式源码和桌面端各保留自己的数据，互不覆盖。实际发布版本、安装包与安装结果以GitHub发布附件及运行验收记录为准。
