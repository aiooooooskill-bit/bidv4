# 当前审核实现

## 输入与取证

受审对象为外部投标文件或平台当前目录对应的正文。招标主文件及补遗是要求来源；投标文件不参与招标要点提取。原件流式落盘，解析生成Markdown、大纲及元信息；审核读大纲导航、分段精读、必要时原文检索并回查后文。Word文字解析及终稿检查只加载所需正文、样式、批注，图片与附件不整包加载。

共享证据纪律来自固定灵燕源码de909f12572b4c469864b12255e26cc185ada7ec：实际原文取证、检索只定位、冲突依据并列、未知不等于缺失。培训周期按条款本意，散落在正文和附件的承诺综合回应；不写死某一文件或数值。

## 单轮审核与程序契约

复用同版有效招标解读；无有效成果时在审查目录生成八份要点。七类要求组成完整catalog，每批最多8项。模型提交slot、判断、双方引用及问题；程序绑定要求ID、提取原文摘录、检查来源角色与范围、完整性和版本，再保存。招标引用须保留原要点所有依据，可按实际精读补充非连续条款。结束前同一Agent可更正已保存批次；全部要求齐备后才发布报告。没有独立业务复审模型。

歧义、来源冲突、图像及外部证明不足直接登记为需确认，并继续完整审核；必需输入缺失、业务规则变化或替用户新增承诺才询问。问题按可能废标、评分失分风险、需确认、建议修改展示；不把所有差异泛化为废标或预测缺少依据的得分。

## 页面与大文件

审核头部提供运行状态、停止、四个文件更新/预览操作与重新审核。报告只有概览、问题清单、招标要点与对照；概览摘要编号展示。有效前序成果和原文证据保留。

投标文件的选择、初次上传、更新及后端落盘不设固定字节上限；招标来源及其他上传限制保留。扫描PDF移除128页硬上限，每页识别前才渲染，全部OCR输出齐备后才发布。图片像素预算、实际磁盘和宿主网络时限仍适用。原件预览属于浏览器单独渲染，不是审核前置条件。

## 当前证据及边界

杭州真实文件完成181条对照和20条意见，完成周期与后文承诺误读已纠正，现场条款引用并列补齐。1.08GB合成Word文件包含12000条索引与128张PNG，真实本地模型完成4条测试义务并引用后文承诺；该证据只证明容量链路，不证明任意真实大文件的所有业务事实都已覆盖。

本平台强制七类前置分析及分批保存是新增编排；相关12份技能文件6份经过适配，不得宣称灵燕整套原流程完全原样复现。原始13条报告与当前报告的差异、保证金问题重复和税务核对提示未单列等业务事项尚未在本轮清理中改变。详见[框架对照](REVIEW-LINGYAN-FRAMEWORK-COMPARISON-2026-10-14.md)和[大文件实测](REVIEW-LARGE-FILE-ACCEPTANCE-2026-10-14.md)。

DOCX图片证照仍为占位，不代表已识别真实性；GB级浏览器原件预览、极大正文XML、海量要求的完整语义覆盖及129页真实模型OCR未完成相应验收。工程检查通过不代表整标无风险。
