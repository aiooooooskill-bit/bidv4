## 一、投标文件结构要求
投标文件按招标文件第二章附件格式编制，包括投标函、投标文件资料清单、声明函、偏离表、技术文件、资格证明文件，可按规定格式扩展。正本与副本分别密封，按顺序胶装成册，一式伍份（1正本4副本），A4纸，蓝黑或黑色墨水打印。投标语言为中文。

**结构大纲：**
- 封面（第二章附件 L533-L548）
- 1．投标函
- 2．投标文件资料清单
- 3．投标供应商关于响应合同签订价规则的声明函
- 4．技术规格响应/偏离表
- 5．商务条款响应/偏离表
- 6．技术文件
  - 6-1 外部数据采购实施案例清单
  - 6-2 投标供应商数据更新承诺函
  - 6-3 投标供应商数据问题处置时效承诺函
  - 6-4 投标供应商数据服务响应时效承诺函
  - 6-5 服务团队清单模板
  - 6-6 合规承诺函
  - 6-7 数据源授权承诺函
- 7．资格证明文件
  - 7-1 具有独立承担民事责任能力的法人或其他组织或自然人的证明材料
  - 7-2 供应商资格信用承诺
  - 7-3 特定资格要求证明材料
  - 7-4 法定代表人授权书
  - 7-5 法定代表人身份证明书
  - 7-6 交纳投标保证金的银行凭证
  - 7-7 无不良信用记录的承诺函
