## 评标办法概述
本次招标采用综合评分法（25.1），技术分50分（数据安全与连续性15分+数据更新承诺5分+通用技术能力10分+售后服务5分+服务团队5分+增值服务10分）+商务分50分（公司资质10分+实施案例40分），满分100分。评审得分由高到低推荐中标候选人，评审得分不低于60分，排名前10名为中标供应商（入围3-10家）。总分相同时按商务分排序，仍相同按技术分排序，仍相同随机抽取。
