# 响应文件：投标文件

本册为整册合并（招标文件要求正本1+副本4胶装成册、同一供应商只投一个投标文件，未要求分册独立递交）。覆盖第二章附件全部必须章节：封面、投标函、投标文件资料清单、响应合同签订价规则声明函、技术规格响应/偏离表、商务条款响应/偏离表、技术文件（6-1 案例清单至 6-7 数据源授权承诺函，含评分要求的技术方案类章节）、资格证明文件（7-1 至 7-8）。技术文件部分同时承载评分标准中技术分全部维度（数据安全与质量及连续性、数据更新承诺、整体技术与架构方案、售后服务、服务团队、增值服务）与商务分中实施案例维度；资质证书复印件等评分材料随资格证明文件部分相应节点归位。与商务/技术/资格的分界不物理拆分，仅在本册目录内以章节区分。
